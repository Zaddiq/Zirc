Zirc

IRC in one web page.

Connect to a chat server from this tab, join channels, and script the client in JavaScript. Nothing to install and no account with us.

  • Connects straight from your browser over WebSocket. Your messages go to the server you pick and nowhere else.
  • Scripts are plain JavaScript. Write them in the built-in editor. They answer commands, greet people, and run timers, like mIRC scripts did.
  • Needs a server that accepts WebSocket. Many large networks don't. See the note under the form.
  • Prefer a terminal? Zirc for Node speaks normal IRC to any network.

Why can't I connect to Libera, OFTC or Rizon?

Browsers can only open WebSocket connections, not the plain TCP sockets that most IRC networks use. A network has to run a WebSocket listener, or you need a gateway such as webircgateway in front of it. If you know a WebSocket address, paste it above.
