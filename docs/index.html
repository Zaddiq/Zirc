IRC you can script in JavaScript.

Zirc is an IRC client for your terminal. Write a few lines of JavaScript to answer commands, greet people, or run timers, the way you once did with mIRC. It has no dependencies and runs anywhere Node does.

Everything a daily-driver client needs

Zirc covers connecting, chatting and keeping your scrollback. The details below are what v0.1 does today.

Connection

  • TLS by default on port 6697
  • SASL PLAIN login, with the password read from an environment variable
  • IRCv3: server-time, multi-prefix, away-notify, account-notify, extended-join, chghost
  • Reconnects with backoff and rejoins your channels
  • An outgoing flood limiter so you don't get kicked for pasting

Interface

  • Channel, private and server windows, with unread and highlight counts
  • A nicklist showing @ and + prefixes
  • mIRC colors, bold, italic, underline and reverse
  • Tab completes nicks, commands and channels
  • Per-window logs in plain text

Everyday commands

  • Join, part, msg, query, me, nick, away, whois
  • Op, voice, kick, ban, topic, mode, invite
  • Ignore lists and custom highlight words
  • Your own aliases such as /ns that expand with $1 and $*
  • /timer for repeating commands

Scripts are just JavaScript files

Put a .js file in ~/.zirc/scripts and type /reload. Your script gets a zirc object, plus require for anything in Node.

// dicebot.js
zirc.on('text', e => {
  if (e.text.startsWith('!roll')) {
    const sides = parseInt(e.text.split(' ')[1], 10) || 6;
    const roll = 1 + Math.floor(Math.random() * sides);
    e.reply(`${e.nick} rolled ${roll} (d${sides})`);
  }
});

// Adds a /shout command
zirc.alias('shout', (args, ctx) => {
  ctx.reply(zirc.fmt.bold(
    zirc.fmt.color(4, args.toUpperCase() + '!')
  ));
});

// Remember when people last spoke
zirc.on('text', e => {
  zirc.store.set('seen:' + e.nick, Date.now());
});

Handle events like text, join, kick, nick, mode and connect. Return false from a handler to stop Zirc from showing or sending that event.

Aliases become slash commands. Timers clean themselves up when you reload. Each script gets its own JSON storage that survives restarts.

If a script throws, Zirc prints the error in your window and carries on. One bad script never takes the client down.

Scripts run with full access to your machine, just like mIRC scripts did. Only load code you trust.

zirc.on(event, fn)Run code when something happens
zirc.alias(name, fn)Add a /name command
zirc.every(ms, fn)Repeat code on a timer; zirc.after runs it once
zirc.say(target, text)Send a message; also action and notice
zirc.store.get / setSave data between sessions
zirc.fmt.color(n, text)Build colored and bold IRC text

Install in three commands

You need Node 18 or newer. Zirc has no packages to install.

$git clone https://github.com/Zaddiq/Zirc
$cd Zirc
$node zirc.js irc.libera.chat -j '#zirc-test'

Zirc creates ~/.zirc/config.json on first run. Set your nick, servers, autojoin channels and SASL login there. Type /help inside Zirc for every command.

Where it stands

Zirc is version 0.1. The protocol layer and scripting engine are covered by automated tests that run against a fake IRC server. What's missing matters if you came from mIRC.

  • Connect, chat, reconnect
  • JavaScript scripting
  • Multiple servers
  • Logs and highlights
  • DCC file transfers and chats
  • SASL EXTERNAL and SCRAM
  • IRCv3 chat history
  • A graphical window version
